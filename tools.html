🧮 满减 Coupon Stacker

How threshold coupons work

满减 (mǎn jiǎn) means "full-reduce": for every ¥300 you spend, you save ¥50. Platforms usually apply store discounts first, then threshold coupons, then flat coupons. Rules vary, so always check the checkout preview.

  • Add a small filler item to cross the next threshold only if you'd buy it anyway.
  • Split large carts into separate orders when thresholds don't stack.
  • Add card or portal cashback on top.
